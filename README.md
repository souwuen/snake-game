# Змейка в терминале

Консольная игра «Змейка» на Python. Змейка ест еду, растёт и с ростом счёта ускоряется. Игра заканчивается, если змейка врезается в стену или в саму себя.

## Требования

- Python 3.11 или новее;
- [uv](https://docs.astral.sh/uv/);
- терминал в Linux или macOS. Интерфейс построен на `curses`, поэтому на Windows игру нужно запускать через WSL.

## Установка

```bash
uv sync
```

Команда создаёт окружение и ставит проект вместе с инструментами разработки (pytest, ruff, mypy).

## Запуск

```bash
uv run python snake.py
```

Параметры (все необязательные):

| Параметр   | По умолчанию | Что задаёт                                  |
|------------|--------------|---------------------------------------------|
| `--width`  | 20           | ширина поля, не меньше 3                    |
| `--height` | 15           | высота поля, не меньше 3                    |
| `--speed`  | 8            | начальная скорость, ходов в секунду, больше 0 |

Пример:

```bash
uv run python snake.py --width 30 --height 20 --speed 5
```

Для поля `W×H` нужно окно не меньше `(W+3)×(H+6)` символов: поле, счёт, подсказки и две строки экрана Game Over. Если окно мало, игра попросит его увеличить и подождёт.

## Управление

| Клавиши               | Действие                                  |
|-----------------------|-------------------------------------------|
| стрелки или `WASD`    | повернуть змейку                          |
| `P`                   | пауза / продолжить                        |
| `Q`                   | выйти                                     |
| `Y` на экране Game Over | сыграть ещё раз                         |

## Правила

- Еда (`*`) появляется в случайной свободной клетке. Каждая съеденная порция даёт +1 к счёту и удлиняет змейку на один сегмент.
- Каждые 5 очков уровень растёт на 1, а интервал между ходами сокращается на 10 % (но не короче 0,05 с). Счёт и уровень показаны под полем.
- Игра заканчивается при столкновении со стеной или с собой, а также если змейка заняла всё поле.
- Разворот на 180° игнорируется, пока змейка длиннее одной клетки.

## Устройство проекта

```text
snake.py              точка входа: python snake.py
snake_game/
  snake.py            класс Snake: тело, движение, рост, самопересечение
  game.py             класс Game: поле, еда, счёт, уровень, конец игры
  cli.py              терминальный интерфейс (curses) и разбор аргументов
tests/                тесты игровой логики
.github/workflows/    CI
```

Логика в `snake_game/snake.py` и `snake_game/game.py` не зависит от терминала и клавиатуры, поэтому тесты запускаются без реального ввода.

## Тесты и проверки

```bash
uv run pytest
uv run ruff check .
uv run ruff format --check .
uv run mypy --strict snake_game tests snake.py
```

Эти же проверки GitHub Actions выполняет при каждом push.
